# crawl-canary

A public test page for Nasup's program-data crawler (Nasup-backend, OPS plan prerequisite O14). It describes a made-up program, the "Canary Manufacturing Training Grant", and says so on the page. The OPS loop edits it to cause the changes its production drills check: an amount or a deadline that changes, a linked document that changes, a layout-only edit, and a page that moves.

It holds no secrets and no real program data. Served by GitHub Pages at https://nasup-ai.github.io/crawl-canary/.
